AURELIS — System Architecture
Three-tier architecture: React/Vite client, Express REST API, SQLite persistence, with an AI/ML decision-support layer
PRESENTATION LAYER

Storefront (React)

Customer-facing shop — catalogue, cart, checkout

Admin Console (React)

Command Center, AI Intelligence, Inventory, Procurement, Reports

Vite Build

SPA bundling, HMR in dev, static assets in production

↓ HTTPS / JSON (fetch, Bearer token auth)
APPLICATION / API LAYER (Express.js)

Auth & RBAC

Staff sessions, permission grants, audit logging

Commerce Routes

Products, Orders, Customers, Categories

Admin Routes

Inventory, Procurement, Warehouses, Cycle Counts, Notes, Reports

ML / AI Routes

Forecast, Risk, Reorder, Anomalies, Feedback, Training

↓
DOMAIN SERVICE LAYER

Inventory Service

adjustStock() — single source of truth for every stock mutation

AI Analytics Engine

Forecasting, stockout risk, reorder proposals, anomaly & overstock detection

ML Trainer & Registry

Model versioning, training runs, candidate algorithm search

Reports & Notes Engine

Scheduled report generation, collaboration & @mentions

↓
PERSISTENCE LAYER

SQLite (node:sqlite)

Single-file relational store — products, orders, inventory, ML versions, audit log

Background Jobs

Sweeper (reservation expiry), Report Scheduler (setInterval-based)

↔ optional, proxied
EXTERNAL / EVALUATED INTEGRATIONS

OpenRouter LLM

Free-tier model chain — explains figures, never invents them

Medusa Commerce Engine

Evaluated second inventory system — read-only comparison, not authoritative
