AURELIS — Entity-Relationship Diagram (Core Schema)
Simplified view of the principal tables and their relationships — SQLite, no ORM
categories
  • slug (PK)
  • name, tag, blurb
  • shape, palette, sub
products
  • id (PK)
  • cat (FK → categories)
  • name, price, stock
  • status, low_stock_at
customers
  • id (PK)
  • email, tier, phone
  • password_hash (never sent to client)
orders
  • id (PK)
  • customer_id (FK)
  • status, stage, channel
  • total, address
order_items
  • id (PK)
  • order_id, product_id (FK)
  • qty, unit_price
warehouses
  • id (PK)
  • code, name, city
warehouse_stock
  • (product_id, warehouse_id)
  • on_hand, reserved, available
  • incoming, safety_stock, reorder_point
inventory_transactions
  • id (PK)
  • product_id, warehouse_id (FK)
  • type, qty, previous_qty, new_qty
  • reason, reference
suppliers
  • id (PK)
  • name, code, lead_time_days
purchase_orders
  • id (PK)
  • supplier_id, warehouse_id (FK)
  • po_number, status, total_value
po_items
  • id (PK)
  • po_id, product_id (FK)
  • qty, unit_cost
cycle_counts
  • id (PK)
  • warehouse_id (FK)
  • count_number, scope, status
cycle_count_items
  • id (PK)
  • cycle_count_id, product_id
  • expected_qty, counted_qty
product_batches
  • id (PK)
  • product_id (FK, parfums only)
  • batch_number, qty, expiry_date
staff
  • id (PK)
  • role_id (FK)
  • email, status
roles
  • id (PK)
  • key, name, rank
audit_logs
  • id (PK)
  • actor, entity, entity_id
  • action, before_val, after_val
ai_alerts
  • id (PK)
  • product_id, warehouse_id (FK)
  • category, severity, status
ai_feedback_outcomes
  • id (PK)
  • model_key, decision, adjusted_to
ml_versions
  • id (PK)
  • model_key, version, is_active
  • algorithm, artifact, wape
ml_runs
  • id (PK)
  • model_key (FK)
  • status, trigger, winner
ml_predictions
  • id (PK)
  • version_id (FK)
  • subject, horizon, value
